Серверная часть специализированной системы управления контентом (CMS) — визуального конструктора сайтов «информационных окон» для образовательных организаций.

Бэкенд отвечает за хранение и управление страницами, блоками, новостями, меню и контактной информацией. Публичный контент предоставляется фронтенду через REST API, а наполнение и администрирование системы выполняются через Django Admin.

**Клиентская часть проекта доступна в репозитории:** [education-cms-frontend](https://github.com/Arteeemis/EDUCATION-CMS-FRONTEND)

## О проекте

Разрабатываемое программное изделие решает проблему фрагментации информационных ресурсов в образовательной среде. Бэкенд реализует две ключевые подсистемы:

1. **Подсистема управления контентом** — хранение страниц и их сборка из упорядоченных блоков различных типов.
2. **Подсистема публикации и администрирования** — выдача опубликованных страниц и новостей через REST API, а также управление пользователями и контентом через административную панель.

Приложение построено на Django и Django REST Framework. Для хранения данных используется PostgreSQL, а для блоков контента применяется полиморфная модель.

## Технологический стек

- **Язык:** Python 3.12+
- **Фреймворк:** Django 5.1.4
- **REST API:** Django REST Framework 3.15.2
- **База данных:** PostgreSQL 16

- **Сортировка объектов в админке:** django-admin-sortable2 2.2.4
- **Работа с PostgreSQL:** psycopg 3.2.3
- **Работа с изображениями:** Pillow 11.0.0
- **Конфигурация окружения:** django-environ 0.11.2
- **CORS:** django-cors-headers 4.6.0
- **Контейнеризация:** Docker и Docker Compose

## Запуск проекта

Для запуска необходимы Docker и Docker Compose, а также файл `.env` в корне репозитория. В нём должны быть заданы параметры приложения, базы данных и разрешённых CORS-источников:

```env
SECRET_KEY=your-secret-key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

DB_NAME=education_cms
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=db
DB_PORT=5432

CORS_ALLOWED_ORIGINS=http://localhost:4200
```

Запуск контейнеров:

```bash
docker compose up --build
```

После запуска:

- API: `http://localhost:8000/api/`
- Административная панель: `http://localhost:8000/admin/`
- PostgreSQL: `localhost:5432`

Миграции и учётная запись администратора создаются отдельными командами:

```bash
docker compose exec backend_cms python manage.py migrate
docker compose exec backend_cms python manage.py createsuperuser
```

## Функциональные возможности

- **Управление страницами:** создание страниц, настройка slug и статуса черновика или публикации.
- **Конструктор страниц:** добавление, удаление, упорядочивание и скрытие блоков.
- **Типы блоков:** HTML, FAQ, новостная лента, Google Документ, Google Таблица, VK Видео, ссылки, меню шапки и контакты подвала.
- **Управление новостями:** заголовки, текст, изображения, авторы, теги, дата публикации и признак важной публикации.
- **Новостные ленты:** группировка публикаций и отображение последних материалов в блоке-превью.
- **Управление навигацией:** настройка пунктов меню, ссылок и контактной информации.
- **Пользователи и права:** администрирование учётных записей, ролей и доступа редакторов к новостным лентам.
- **Django Admin:** единая панель управления контентом и пользователями с сортировкой объектов.
